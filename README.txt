WEBXR - CUBO AR

Contenido:
- index.html
- css/style.css
- js/app.js

Requisitos:
1. Abrir el proyecto en VS Code.
2. Ejecutarlo mediante un servidor local.
3. Para probar WebXR AR en un teléfono, usar un navegador/dispositivo compatible.
4. WebXR normalmente requiere HTTPS, excepto localhost durante desarrollo.

Estructura:
webxr-cubo-ar/
├── index.html
├── css/
│   └── style.css
└── js/
    └── app.js

El proyecto usa:
- HTML
- CSS
- JavaScript
- Three.js
- WebXR
